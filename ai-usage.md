# AI Usage Documentation

Dalam pengerjaan project **helpdesk-api** ini, penulis menggunakan AI sebagai alat bantu (tools) kolaborasi untuk:
- Memahami panduan langkah demi langkah dari modul praktikum (Modul 1 & Modul 2).
- Membantu menyusun struktur kode Go Fiber secara bertahap (memisahkan `main.go`, `model.go`, `helper.go`, dan `handler.go`).
- Menerapkan praktik terbaik HTTP semantics (metode safe/idempotent, status code yang tepat, perbedaan PUT vs PATCH, serta query handling).
- Menyusun dokumentasi pendukung seperti README, kontrak API, dan laporan project.
